# Signal Map 0.1.6

LUNA routing inspection by Førm Sonics.

- Trace tracks and buses through main outputs and sends.
- Explore a readable session map with search, panning, zoom and overview navigation.
- Inspect channel status and SDK meters; distinguish unavailable data from confirmed problems.
- Locate a selected channel in LUNA without changing audio controls.
- Consistent DM Sans typography and the upright original FORM symbol.
- Clean release package with SDK/font notices and no obsolete logo asset.
- Fix Locate in LUNA rejecting an unsupported context-focus value.
- Correct displayed version and updated usage/data-handling documentation.

Limitations: cue routing, plugin internals, hardware cabling and Apollo Console are not inspected. Graphs are limited to 512 nodes. Demo data is synthetic. No automatic audio fixes or routing edits.

Compatibility: LUNA 3.1.2 or compatible newer host; macOS validation. Native installation and primary workflow confirmed by the owner; see docs/VERIFICATION.md in the repository for evidence scope.
