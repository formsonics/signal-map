# Signal Map data handling

Signal Map reads session/channel names, identifiers, routing assignments and SDK meter/state values from LUNA to display its interface. These are held in memory, not sent to a cloud service by Signal Map. It contains no analytics, advertising, account login or external API integration. The SDK communicates with the local LUNA engine.

The add-on does not persist a user library, audio recordings or account credentials. It does not upload audio or session data. Locate explicitly changes LUNA's channel selection and mixer page; audio controls are not edited.

GitHub and UA Universe separately process downloads, account sign-in and support/submission activity under their own policies. When reporting a problem, redact private session names and client information from screenshots.
