# Release checklist

- [x] Isolated repository and consistent app branding
- [x] Runtime includes SDK and font notices
- [x] Packaging excludes development files and unused rendered logo
- [ ] Native LUNA installation/open/close and real primary workflow
- [ ] Session switching/disconnection and applicable navigation/audio/undo checks
- [ ] Save, close, reopen and backup export/import checks
- [ ] Update/reinstall persistence verified and documented
- [ ] User guide synchronized with native observations
- [ ] Public support address and final licensing/distribution decision
- [ ] Clean screenshots and user-facing release notes
- [ ] File/rights/privacy review before making repository public
- [ ] Stable tag and non-draft, non-prerelease release with `.lunaaddon`
- [ ] Download checksum and UA official checker pass
- [ ] UA submission, review and marketplace installation verified

No public release or submission is implied by completion of repository setup.
